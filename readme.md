# Домашнее задание к работе 2

## Условие задачи

**Вариант 11:** Напишите программу, которая считывает системное время компьютера и выводит на экран текущее московское время, а также время года и две последние цифры года. Вывод должен быть организован точно в центре строки экрана (шириной 80 символов) в виде прямоугольного окна высотой в 10 строк, заполненного символами '*'. Для подготовки строк использовать функцию `sprintf()`.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Объявить служебные переменные: указатель на структуру `struct tm *mytime` и переменную `time_t t`.
3. Считать текущее календарное системное время в секундах с помощью функции `time(NULL)`.
4. Трансформировать полученное время в локальное с заполнением полей структуры с помощью функции `localtime(&t)`.
5. Извлечь из структуры номер текущего месяца `tm_mon` и вычислить две последние цифры года на основе поля `tm_year`.
6. С помощью ветвления определить текущее время года (Зима, Весна, Лето или Осень) по номеру месяца.
7. Сформировать строку с текущим московским временем через функцию `sprintf()`.
8. Сформировать вторую строку с временем года и двумя последними цифрами года через функцию `sprintf()`.
9. Запустить цикл от 1 до 10 для вывода прямоугольного окна на экран.
10. На 5-й и 6-й итерациях цикла вывести сформированные строки, предварительно рассчитав количество звездочек слева и справа для центрирования на ширину 80 символов.
11. На всех остальных итерациях вывести сплошные строки, состоящие из 80 символов '*'.
12. **Конец**

## 2. Реализация программы

```c
#include <stdio.h>
#include <time.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "RU.UTF8");

    struct tm *mytime;
    time_t t;

    t = time(NULL);
    mytime = localtime(&t);

    int m = mytime->tm_mon;
    const char *season = (m == 11 || m <= 1) ? "Зима" : (m <= 4) ? "Весна" : (m <= 7) ? "Лето" : "Осень";
    int year2 = (mytime->tm_year + 1900) % 100;

    char time_msg[100];
    char option_msg[100];

    sprintf(time_msg, " Московское время %02d:%02d:%02d ", mytime->tm_hour, mytime->tm_min, mytime->tm_sec);
    sprintf(option_msg, " Время года: %s | Год: '%02d ", season, year2);

    int len1 = 27; 
    int len2 = (m == 11 || m <= 1 || m >= 8) ? 30 : 29; 

    int s1 = (80 - len1) / 2;
    int s2 = (80 - len2) / 2;

    for (int r = 1; r <= 10; r++) {
        if (r == 5) {
            for (int i = 0; i < s1; i++) printf("*");
            printf("%s", time_msg);
            for (int i = 0; i < (80 - s1 - len1); i++) printf("*");
        } else if (r == 6) {
            for (int i = 0; i < s2; i++) printf("*");
            printf("%s", option_msg);
            for (int i = 0; i < (80 - s2 - len2); i++) printf("*");
        } else {
            for (int i = 0; i < 80; i++) printf("*");
        }
        printf("\n");
    }

    return 0;
}
```
